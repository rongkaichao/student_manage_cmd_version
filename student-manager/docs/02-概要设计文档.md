# 概要设计文档

## 1. 设计目标

基于需求规格说明书，设计学生管理系统的整体架构，明确模块划分、模块职责和模块间的交互关系。

## 2. 系统架构

本系统采用**分层架构**，分为三层：

```
+---------------------------+
|     表现层 (main.cpp)      |  ← 用户交互：菜单显示、输入接收
+---------------------------+
|   业务逻辑层 (StudentManager) |  ← 核心业务：增删改查、统计、文件读写
+---------------------------+
|   数据模型层 (Student)       |  ← 数据封装：属性、序列化/反序列化
+---------------------------+
|   持久化存储 (students.txt)   |  ← 文件存储：CSV 格式文本文件
+---------------------------+
```

## 3. 模块划分

### 3.1 模块一览

| 模块 | 文件 | 职责 |
|-----|------|------|
| 主程序入口 | `main.cpp` | 显示菜单、接收用户选择、调用管理器 |
| 学生模型 | `Student.h` / `Student.cpp` | 封装学生数据，提供序列化/反序列化 |
| 学生管理器 | `StudentManager.h` / `StudentManager.cpp` | 业务逻辑核心：增删改查、统计、文件I/O |

### 3.2 模块依赖关系

```
main.cpp  ──→  StudentManager  ──→  Student
                  │                    │
                  └──→ students.txt    └──→ CSV 序列化
```

- `main.cpp` 只依赖 `StudentManager`，不直接操作 `Student`
- `StudentManager` 管理 `Student` 对象集合，负责文件读写
- `Student` 是纯数据模型，不依赖其他模块

## 4. 核心类设计

### 4.1 Student 类

```
Student
├── 属性: id, name, age, score
├── getter: getId(), getName(), getAge(), getScore()
├── setter: setName(), setAge(), setScore()
├── display()          // 控制台输出
├── toString()         // 序列化为 CSV 字符串
└── fromString()       // 从 CSV 字符串解析（静态方法）
```

**设计要点**：
- `id` 没有 setter，创建后不可修改，保证唯一性
- `toString()` / `fromString()` 负责数据的序列化和反序列化，与存储格式解耦

### 4.2 StudentManager 类

```
StudentManager
├── 属性: students (vector<Student>), filePath (string), nextId (int)
├── 私有方法: loadFromFile(), saveToFile()
└── 公有方法: addStudent(), deleteStudent(), modifyStudent(),
             queryStudent(), displayAll(), showStatistics()
```

**设计要点**：
- `students` 使用 `std::vector` 存储，适合小规模数据的随机访问
- `nextId` 在加载文件时自动计算（取最大 ID + 1），保证自增唯一
- 每次增删改操作后立即调用 `saveToFile()`，全量写入

## 5. 数据流图

### 5.1 添加学生流程

```
用户输入 → main.cpp 接收 → StudentManager.addStudent()
  → 创建 Student 对象 → 存入 vector → saveToFile() → 写入文件
```

### 5.2 查询学生流程

```
用户选择查询方式 → main.cpp 接收 → StudentManager.queryStudent()
  → 遍历 vector 匹配 → 输出结果到控制台
```

### 5.3 文件读写流程

```
启动时: 构造 StudentManager → loadFromFile() → 逐行解析 CSV → 填充 vector
运行中: 增/删/改 → saveToFile() → vector 全量写出到文件
```

## 6. 关键设计决策

| 决策点 | 选择 | 理由 |
|-------|------|------|
| 存储方案 | 本地 CSV 文件 | 轻量、无需数据库依赖、便于人工查看 |
| 数据结构 | vector | 数据量小，支持随机访问，简单高效 |
| 写入策略 | 全量覆写 | 实现简单，数据量小性能可接受 |
| ID 分配 | 自增整数 | 保证唯一，用户无需手动输入 |
| 输入方式 | std::cin 逐字段 | 实现简单，控制台交互直观 |
