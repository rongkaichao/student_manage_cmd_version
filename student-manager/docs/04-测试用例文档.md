# 测试用例文档

## 1. 测试范围

覆盖学生管理系统所有 6 个功能模块，包括正常流程和异常流程。

## 2. 测试用例

### 2.1 添加学生 (FR-001)

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|
| TC-001 | 正常添加 | name=Tom, age=20, score=85 | 提示添加成功，显示学生信息，文件中新增一行 |
| TC-002 | 连续添加多名学生 | 依次添加 3 名学生 | 每次学号递增，文件包含 3 行数据 |
| TC-003 | 年龄为边界值 0 | age=0, score=50 | 添加成功 |
| TC-004 | 年龄为边界值 150 | age=150, score=50 | 添加成功 |
| TC-005 | 成绩为边界值 0 | age=20, score=0 | 添加成功 |
| TC-006 | 成绩为边界值 100 | age=20, score=100 | 添加成功 |
| TC-007 | 年龄越界（负数） | age=-1 | 提示 "Invalid age!"，不写入文件 |
| TC-008 | 年龄越界（超 150） | age=151 | 提示 "Invalid age!"，不写入文件 |
| TC-009 | 成绩越界（负数） | score=-1 | 提示 "Score must be 0-100!"，不写入文件 |
| TC-010 | 成绩越界（超 100） | score=101 | 提示 "Score must be 0-100!"，不写入文件 |

### 2.2 删除学生 (FR-002)

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|
| TC-011 | 正常删除 | id=1, 确认 y | 提示删除成功，文件中该记录消失 |

| TC-013 | 删除不存在的学号 | id=999 | 提示 "not found" |
| TC-014 | 空数据时删除 | 无数据时选择删除 | 提示 "No records." |

### 2.3 修改学生 (FR-003)

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|
| TC-015 | 修改全部字段 | id=1, name=NewName, age=22, score=90 | 三个字段全部更新 |
| TC-016 | 仅修改姓名 | name=NewName, age=-1, score=-1 | 仅姓名变化，其余不变 |
| TC-017 | 仅修改成绩 | name=-, age=-1, score=95 | 仅成绩变化 |
| TC-018 | 修改不存在的学号 | id=999 | 提示 "not found" |
| TC-019 | 空数据时修改 | 无数据时选择修改 | 提示 "No records." |

### 2.4 查询学生 (FR-004)

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|
| TC-020 | 按学号查询（存在） | 方式=1, id=1 | 显示该学生信息 |

| TC-022 | 按姓名查询（存在） | 方式=2, name=Tom | 显示匹配的学生信息 |

### 2.6 统计信息 (FR-006)

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|

### 2.7 数据持久化

| 用例编号 | 测试场景 | 操作 | 预期结果 |
|---------|---------|------|---------|
| TC-033 | 添加后重启验证 | 添加学生 → 退出 → 重新启动 → 显示全部 | 之前添加的学生仍存在 |
| TC-034 | 删除后重启验证 | 删除学生 → 退出 → 重新启动 → 显示全部 | 被删除的学生不存在 |
| TC-035 | 修改后重启验证 | 修改学生 → 退出 → 重新启动 → 查询 | 修改内容已持久化 |

### 2.8 菜单输入异常

| 用例编号 | 测试场景 | 输入 | 预期结果 |
|---------|---------|------|---------|
| TC-036 | 菜单输入字母 | 输入 abc | 提示 "Invalid input"，不崩溃 |
| TC-037 | 菜单输入无效数字 | 输入 99 | 提示 "Invalid choice." |

## 3. 执行建议

- 按编号顺序执行，先执行添加相关用例，为后续删除/修改/查询准备数据
- 每轮测试前清空 `data/students.txt` 或删除该文件，确保环境干净
- TC-033 ~ TC-035 需要退出并重启程序来验证持久化
