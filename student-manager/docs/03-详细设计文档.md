# 详细设计文档

## 1. 目的

对概要设计中的每个模块进行细化，描述核心函数的算法逻辑、数据结构细节和边界处理，为编码提供直接依据。

## 2. Student 类详细设计

### 2.1 数据成员

| 成员 | 类型 | 说明 |
|-----|------|------|
| id | int | 学号，构造时赋值，无 setter |
| name | string | 姓名 |
| age | int | 年龄 |
| score | double | 成绩 |

### 2.2 序列化格式

CSV 格式，字段顺序：`id,name,age,score`

**toString() 算法**：
```
使用 ostringstream
依次写入 id, ",", name, ",", age, ",", score
返回拼接后的字符串
```

**fromString() 算法**：
```
使用 istringstream 包装输入字符串
用 getline(iss, token, ',') 依次读取 4 个字段
前两个整数字段用 stoi 转换，浮点字段用 stod 转换
构造并返回 Student 对象
```

## 3. StudentManager 类详细设计

### 3.1 构造函数

```
StudentManager(filePath):
    this.filePath = filePath
    this.nextId = 1
    调用 loadFromFile()
```

### 3.2 loadFromFile()

```
以 ifstream 打开 filePath
如果打开失败，直接返回（文件不存在是正常情况）
逐行读取：
    跳过空行
    调用 Student::fromString() 解析每行
    将 Student 加入 students 向量
    如果 student.id >= nextId，则 nextId = student.id + 1
关闭文件
```

### 3.3 saveToFile()

```
提取 filePath 中的目录部分
如果目录不存在，调用 _mkdir() 创建
以 ofstream（截断模式）打开 filePath
如果打开失败，输出错误信息并返回
遍历 students 向量，逐个调用 toString() 写入文件
关闭文件
```

### 3.4 addStudent()

```
输出 "--- Add Student ---"
提示输入 name、age、score
读取输入
校验 age：不在 [0,150] 范围则输出错误，return
校验 score：不在 [0,100] 范围则输出错误，return
创建 Student(nextId++, name, age, score)
加入 students 向量
调用 saveToFile()
输出 "Added successfully!" 并显示该学生信息
```

### 3.5 deleteStudent()

```
如果 students 为空，输出 "No records." 并 return
提示输入学号
使用 find_if + lambda 在 students 中查找
如果未找到，输出 "not found" 并 return
显示该学生信息，询问是否确认删除
如果输入 'y' 或 'Y'：
    从 students 中 erase 该元素
    调用 saveToFile()
    输出 "Deleted!"
否则输出 "Cancelled."
```

### 3.6 modifyStudent()

```
如果 students 为空，输出提示并 return
提示输入学号
使用 find_if 查找
如果未找到，输出提示并 return
显示当前信息
逐项提示输入新值：
    name: 输入 "-" 表示跳过
    age:  输入 -1 表示跳过
    score: 输入 -1 表示跳过
调用 saveToFile()
输出 "Updated!" 并显示更新后信息
```

### 3.7 queryStudent()

```
如果 students 为空，输出提示并 return
提示选择查询方式：1=按学号，2=按姓名
按学号：
    使用 find_if 精确匹配
    找到则 display()，否则输出 "Not found."
按姓名：
    遍历 students，逐一比较 name
    匹配则 display()，记录 found=true
    遍历结束后 found 仍为 false 则输出 "Not found."
```

### 3.8 displayAll()

```
如果 students 为空，输出提示并 return
输出表头（ID, Name, Age, Score），使用 setw 对齐
遍历 students，逐行格式化输出
```

### 3.9 showStatistics()

```
如果 students 为空，输出提示并 return
初始化：total=0, maxScore/minScore=首条记录的score, passCount=0
遍历 students：
    total 累加 score
    更新 maxScore / minScore 及对应姓名
    score >= 60 则 passCount++
计算 avg = total / students.size()
输出：总人数、平均分、最高分、最低分、及格率
```

## 4. main.cpp 详细设计

```
main():
    创建 StudentManager，传入 "data/students.txt"
    循环：
        调用 showMenu() 显示菜单
        读取 choice
        如果 cin 失败（非数字输入）：
            清除错误标志，忽略缓冲区，提示重新输入，continue
        switch(choice):
            1 → addStudent()
            2 → deleteStudent()
            3 → modifyStudent()
            4 → queryStudent()
            5 → displayAll()
            6 → showStatistics()
            0 → 输出 "Bye!", return 0
            default → 输出 "Invalid choice."
```

## 5. 边界条件与异常处理

| 场景 | 处理方式 |
|-----|---------|
| 数据文件不存在 | loadFromFile 直接返回，首次写入时自动创建 |
| 数据文件目录不存在 | saveToFile 中用 _mkdir 自动创建 |
| 输入非数字（age/score） | cin.fail() 检测，清除标志并提示重新输入（仅 main 中处理） |
| 学号不存在 | find_if 返回 end()，输出未找到提示 |
| students 为空时操作 | 各函数入口检查并提前返回 |
| 年龄/成绩越界 | addStudent 中校验，不合法则不写入 |
