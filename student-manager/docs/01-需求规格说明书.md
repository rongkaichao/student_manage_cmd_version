# 需求规格说明书

## 1. 项目概述

| 项目名称 | 学生管理系统 (Student Manager) |
|---------|-------------------------------|
| 版本    | v1.0                          |
| 编写日期 | 2026-03-26                    |
| 描述    | 基于 C++ 的命令行学生信息管理工具 |

## 2. 项目背景

开发一个轻量级的学生信息管理系统，用于对在校学生的基本信息（学号、姓名、年龄、成绩）进行增删改查操作，数据持久化存储在本地文本文件中。

## 3. 用户角色

| 角色 | 描述 |
|-----|------|
| 管理员 | 使用本系统的唯一用户，负责学生信息的录入、修改、删除和查询 |

## 4. 功能需求

### 4.1 添加学生 (FR-001)
- **描述**：录入一名新学生的信息
- **输入**：姓名、年龄、成绩
- **处理**：
  - 系统自动生成唯一学号（递增）
  - 校验年龄范围：0 ~ 150
  - 校验成绩范围：0 ~ 100
- **输出**：提示添加成功，显示该学生信息，数据写入文件
- **异常**：输入非法时给出错误提示，不写入数据

### 4.2 删除学生 (FR-002)
- **描述**：根据学号删除一名学生
- **输入**：学号
- **处理**：查找对应学号的学生，确认后删除，更新文件
- **输出**：提示删除成功或未找到
- **异常**：学号不存在时提示未找到

### 4.3 修改学生 (FR-003)
- **描述**：修改已有学生的信息
- **输入**：学号、新的姓名（可选）、年龄（可选）、成绩（可选）
- **处理**：按学号查找学生，逐项修改，跳过标记为"-1"（年龄/成绩）或"-"（姓名）的字段
- **输出**：提示修改成功，显示更新后的信息
- **异常**：学号不存在时提示未找到

### 4.4 查询学生 (FR-004)
- **描述**：按学号或姓名查找学生
- **输入**：查询方式（1=按学号，2=按姓名）、查询值
- **处理**：遍历数据进行精确匹配
- **输出**：显示匹配的学生信息
- **异常**：无匹配结果时提示未找到

### 4.5 显示全部 (FR-005)
- **描述**：以表格形式展示所有学生信息
- **输入**：无
- **处理**：遍历所有记录，格式化输出
- **输出**：包含学号、姓名、年龄、成绩的表格

### 4.6 统计信息 (FR-006)
- **描述**：对所有学生的成绩进行统计
- **输入**：无
- **处理**：计算总人数、平均分、最高分、最低分、及格率（≥60）
- **输出**：统计结果

## 5. 非功能需求

| 编号 | 类别 | 要求 |
|-----|------|------|
| NFR-001 | 性能 | 支持管理至少 10000 条学生记录 |
| NFR-002 | 可靠性 | 每次修改操作后立即持久化到文件，防止数据丢失 |
| NFR-003 | 兼容性 | 支持 Windows 平台，使用 g++ 编译 |
| NFR-004 | 数据格式 | 使用 CSV 纯文本存储，便于人工查看和迁移 |

## 6. 数据定义

### 学生实体 (Student)

| 字段 | 类型 | 说明 | 约束 |
|-----|------|------|------|
| id | int | 学号（唯一标识） | 系统自动生成，不可修改 |
| name | string | 姓名 | 非空 |
| age | int | 年龄 | 0 ~ 150 |
| score | double | 成绩 | 0 ~ 100 |

### 存储格式

文件路径：`data/students.txt`
格式：每行一条记录，CSV 格式：`id,name,age,score`

```
1,Alice,20,85.5
2,Bob,21,92.0
```

## 7. 约束与假设

- 系统为单用户使用，不考虑并发
- 姓名不含逗号（CSV 分隔符）
- 数据文件存储在程序运行目录下的 `data/` 子目录中
