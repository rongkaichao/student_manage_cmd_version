# 用户使用手册

## 1. 简介

学生管理系统 (Student Manager v1.0) 是一个命令行工具，用于管理学生的基本信息。支持添加、删除、修改、查询学生信息，并提供数据统计功能。

## 2. 运行环境

- 操作系统：Windows
- 编译器：g++ (支持 C++17)

## 3. 编译方法

在 `student-manager/` 目录下执行：

```bash
g++ -o student_manager.exe src/main.cpp src/Student.cpp src/StudentManager.cpp -std=c++17
```

## 4. 运行方法

```bash
./student_manager.exe
```

> 注意：请在 `student-manager/` 目录下运行程序，数据文件会保存在当前目录的 `data/students.txt` 中。

## 5. 功能说明

### 5.1 主菜单

```
=============================
  Student Manager v1.0
=============================
  1. Add Student
  2. Delete Student
  3. Modify Student
  4. Query Student
  5. Display All
  6. Statistics
  0. Exit
=============================
Choose:
```

输入数字选择对应功能，输入 `0` 退出程序。

### 5.2 添加学生

选择 `1`，依次输入：
- **姓名**：任意文本（不含空格）
- **年龄**：0 ~ 150 的整数
- **成绩**：0 ~ 100 的数值（可含小数）

学号由系统自动生成。

### 5.3 删除学生

选择 `2`，输入要删除的学生学号，确认后输入 `y` 删除。

### 5.4 修改学生

选择 `3`，输入学号找到学生后：
- 输入新姓名，或输入 `-` 跳过
- 输入新年龄，或输入 `-1` 跳过
- 输入新成绩，或输入 `-1` 跳过

### 5.5 查询学生

选择 `4`，选择查询方式：
- `1` 按学号查询：输入学号精确查找
- `2` 按姓名查询：输入姓名精确查找（会显示所有同名学生）

### 5.6 显示全部

选择 `5`，以表格形式显示所有学生信息。

### 5.7 统计信息

选择 `6`，显示以下统计数据：
- 总人数
- 平均分
- 最高分（及对应学生）
- 最低分（及对应学生）
- 及格率（成绩 ≥ 60 分的比例）

## 6. 数据文件

数据存储在 `data/students.txt` 中，CSV 格式，每行一条记录：

```
1,Alice,20,85.5
2,Bob,21,92
```

可直接用文本编辑器查看和编辑（需保持格式正确）。
